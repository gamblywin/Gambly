# GAMBLY Sprint 23.2 — inicialização no Windows

Abra esta pasta diretamente no VS Code. O `package.json` precisa aparecer
na raiz da pasta aberta.

No terminal do VS Code:

```powershell
npm install
npm start
```

Depois abra no navegador:

http://localhost:3000/

O terminal pode mostrar `0.0.0.0:3000` como endereço de escuta do servidor.
Isso é normal. Para acessar pelo próprio computador, use `localhost:3000`.

Para parar o servidor: `Ctrl + C`.
